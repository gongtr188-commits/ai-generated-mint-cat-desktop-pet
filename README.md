# 薄荷（猫猫）· Mint Cat Desktop Pet

PyQt5 无边框透明桌宠：薄荷（猫猫）会自己在桌面上走走停停，也会被你逗、陪你玩。代码与美术资产均由 AI 生成。

## 功能

- 随机漫游：取点走过去，撞墙只查前导边，不会卡住
- 姿态系统：正面 / 左右侧面、坐下、趴下、趴着睡，姿态互斥就地切换
- 转身与朝向：按最短路径转身，起步相位对齐，切换不跳帧
- 动作池：打瞌睡、抱抱、跑步等一次性动作，可被手动指令抢占
- 跟随鼠标：实时连续跟随（retarget），松手恢复漫游
- 呼吸与抖动处理：静立呼吸、运行时序列平滑，减少高频抖动

## 快速开始

需要 Python 3.10+（Windows）。

```bat
py -3 -m pip install -r requirements.txt
```

双击 `启动薄荷猫猫.bat`，或在项目根目录执行：

```bat
set PYTHONPATH=src
py -3 -m mint_pet
```

## 目录结构

| 路径 | 说明 |
| --- | --- |
| `src/mint_pet/` | 桌宠主程序（窗口、姿态、行为、漫游、交互） |
| `assets/` | `manifest.json` 与按姿态切好的帧序列 |
| `素材/` | 原始图片与视频素材 |
| `tools/` | 素材管线（抠图、切帧、描边、检查）与回归脚本 |
| `docs/` | 开发文档、需求清单、素材规范、诊断预览 |

文档入口：`docs/开发文档.md`、`docs/需求清单.md`、`docs/素材规范.md`。
